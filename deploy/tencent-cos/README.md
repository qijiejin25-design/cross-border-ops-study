# 腾讯云 COS 国内部署说明

目标：把 `dist/index.html` 上传到腾讯云 COS，开启静态网站，得到微信里更容易直接打开的国内链接。

## 你需要准备

1. 腾讯云账号。
2. 一个 COS 存储桶，建议地域选中国大陆，例如广州、上海、北京。
3. 开启静态网站功能，索引文档填 `index.html`。
4. 设置文件可公开读取。
5. 最好绑定你自己的已备案域名，例如 `study.example.com`。

## 推荐权限

不要给主账号密钥。新建一个临时子账号，只给这个存储桶的权限：

- 上传对象
- 读取对象
- 设置对象 ACL
- 设置静态网站配置

## 部署文件

上传这个文件：

```text
dist/index.html
```

上传后访问根路径即可，例如：

```text
https://你的域名/
```

或 COS 静态网站域名，具体以腾讯云控制台显示为准。

## 注意

腾讯云文档提示：2024 年 1 月 1 日后创建的存储桶，如果直接用 COS 静态网站域名访问，可能会出现下载行为；微信里长期稳定访问更建议绑定自定义域名。
