# 阿里云 OSS 国内部署说明

目标：把 `dist/index.html` 上传到阿里云 OSS，开启静态网站托管，得到微信里更容易直接打开的国内链接。

## 你需要准备

1. 阿里云账号。
2. 一个 OSS Bucket，建议地域选中国大陆，例如杭州、上海、深圳。
3. 开启静态网站托管，默认首页填 `index.html`。
4. 设置文件可公开读取。
5. 最好绑定你自己的已备案域名，例如 `study.example.com`。

## 推荐权限

不要给主账号 AccessKey。新建一个临时 RAM 用户，只给这个 Bucket 的权限：

- 上传文件
- 读取文件
- 设置静态网站

## 部署文件

上传这个文件：

```text
dist/index.html
```

上传后访问根路径即可，例如：

```text
https://你的域名/
```

或 OSS 静态网站托管地址，具体以阿里云控制台显示为准。
