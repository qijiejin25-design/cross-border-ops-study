# 02 跨境运营基础框架

这份文件回答图片里的第一个需求：跨境运营基础框架，以及 CTR、CVR、ROI、用户画像、内容策略、选品逻辑、流量来源等基础问答。

## 1. 一句话理解跨境运营

跨境运营就是在海外平台上，用合适的商品、内容、价格和服务，把目标用户从“看到”一步步推到“下单、复购、推荐”。

## 2. 运营闭环

完整闭环：

1. 市场调研：哪个国家、哪个人群、哪个需求值得做。
2. 选品：卖什么，利润是否成立，供应是否稳定。
3. 商品包装：标题、图片、视频、卖点、价格、评价。
4. 流量获取：搜索、推荐、广告、达人、直播、活动、站外。
5. 转化优化：让用户信任并下单。
6. 履约售后：发货、物流、退换货、客服、评价。
7. 数据复盘：看数据，找到问题，继续优化。

## 3. 基础指标

### CTR 点击率

CTR = 点击次数 / 展示次数

含义：用户看到你的内容、广告或商品后，有多少人愿意点击。

例子：视频商品卡展示 10,000 次，点击 300 次，CTR = 3%。

CTR 低通常说明：

- 封面不吸引人
- 标题没有利益点
- 商品不匹配用户需求
- 价格没有吸引力
- 前 3 秒没有抓住注意力

### CVR 转化率

CVR = 成交订单数 / 点击人数

含义：点进来的人，有多少人最后下单。

例子：商品页有 500 人进入，25 人下单，CVR = 5%。

CVR 低通常说明：

- 商品页卖点不清楚
- 价格不够有竞争力
- 评价少或差评明显
- 物流时效慢
- 运费高
- 用户信任不足
- 商品和视频承诺不一致

### ROI 投入产出比

ROI = 收益 / 投入

电商里经常用来粗略看“花的钱换回多少销售额或利润”。如果广告花 100 美元带来 300 美元销售额，按销售额算 ROI = 3。

注意：ROI 只看销售额不等于赚钱。真正要看利润，还要扣商品成本、佣金、物流、退货和人工。

### ROAS 广告支出回报

ROAS = 广告带来的销售额 / 广告花费

例子：广告花费 100 美元，广告归因销售额 500 美元，ROAS = 5。

面试可以这样说：ROAS 更常用于广告投放评估，ROI 更偏整体投入产出和利润视角。

### GMV 成交总额

GMV = 所有成交订单金额总和，通常没有扣除退款、成本和佣金。

GMV 高不一定代表利润高。

### AOV 客单价

AOV = 销售额 / 订单数

提升方式：

- 套装组合
- 满减满赠
- 关联销售
- 多件折扣
- 升级款推荐

### CAC 获客成本

CAC = 获取一个新客户的成本。

如果一个新客户平均利润是 10 美元，但获客成本是 15 美元，长期会亏。

### LTV 用户生命周期价值

LTV = 一个用户在长期内能贡献的总利润或总销售额。

复购型产品更关注 LTV，比如美妆、宠物用品、耗材。

## 4. 用户画像

用户画像不是“女性，20-30 岁”这么简单。好的用户画像要回答：

- 他是谁：年龄、性别、国家、职业、收入、家庭状态。
- 他有什么痛点：怕麻烦、怕贵、怕不好用、怕不安全、怕丑。
- 他什么时候需要：季节、节日、生活场景、突发事件。
- 他为什么现在会买：折扣、趋势、礼物、刚需、替代品坏了。
- 他在哪里看到内容：TikTok、Instagram、Amazon、Google、Shopee。
- 他购买前担心什么：尺寸、质量、物流、退货、真假、售后。

用户画像模板：

| 维度 | 示例 |
|---|---|
| 国家 | 美国 |
| 人群 | 25-35 岁租房女性 |
| 场景 | 小户型收纳 |
| 痛点 | 空间小、东西乱、希望便宜好安装 |
| 触发点 | 搬家、新年整理、TikTok 收纳视频 |
| 内容钩子 | “10 秒让洗手台变整洁” |
| 购买顾虑 | 尺寸不合适、承重差、安装复杂 |
| 转化动作 | 展示安装过程、尺寸对比、真实评价 |

## 5. 内容策略

内容策略 = 给什么人，在什么场景下，用什么形式，说什么卖点，让他产生什么动作。

常见内容类型：

- 痛点型：先展示问题，再展示产品解决。
- 对比型：使用前 vs 使用后，普通产品 vs 我们产品。
- 测评型：真实测试、防水测试、承重测试、开箱测试。
- 教程型：教用户如何使用。
- 场景型：把产品放进生活场景中，比如厨房、旅行、健身。
- 趋势型：借热点音乐、挑战、节日、话题。
- 口碑型：用户评价、达人推荐、买家秀。

内容不是为了“好看”，而是为了让用户快速理解：

1. 这是什么？
2. 对我有什么用？
3. 为什么比别的好？
4. 我现在买有什么理由？

## 6. 选品逻辑

基础选品公式：

需求存在 + 竞争可控 + 利润足够 + 供应稳定 + 合规可卖 + 内容好展示 = 值得测试。

### 需求判断

- 平台搜索量是否高。
- 同类产品是否有销量和评论。
- TikTok/Instagram 是否有相关内容热度。
- Google Trends 是否有上升趋势。
- 是否有季节、节日或场景需求。

### 竞争判断

- 同类商品数量多不多。
- 头部卖家的评论是否非常多。
- 价格是否已经打到很低。
- 是否有品牌垄断。
- 新卖家是否还能靠内容或差异化切入。

### 利润判断

至少要算：

- 采购成本
- 国内运输
- 头程国际物流
- 平台佣金
- 支付费
- 仓储费
- 尾程配送
- 广告费
- 退货损耗
- 包装成本

新手不要只看毛利率，要看“扣完所有费用后还剩多少”。

### 内容判断

适合 TikTok 的产品一般有这些特征：

- 视觉变化明显
- 使用前后对比强
- 3 秒内能看懂
- 有新奇感或实用性
- 价格不需要长时间决策
- 能被达人自然种草

## 7. 流量来源

| 流量类型 | 来源 | 优点 | 风险 |
|---|---|---|---|
| 自然搜索 | 平台搜索关键词 | 精准，用户购买意图强 | 需要关键词、评价和权重 |
| 推荐流 | TikTok For You、平台猜你喜欢 | 爆发力强 | 不稳定，依赖内容质量 |
| 广告 | TikTok Ads、Meta、Google、平台广告 | 可放量，可测试 | 烧钱快，需要数据能力 |
| 达人联盟 | Creator/Affiliate | 信任感强，可借达人内容 | 达人质量参差不齐 |
| 直播 | TikTok Live、Shopee Live | 互动强，适合促销 | 要人、脚本、节奏和场控 |
| 活动 | 平台大促、秒杀、优惠券 | 短期冲量 | 利润下降，库存压力大 |
| 站外 | 社媒、社区、邮件、SEO | 可沉淀用户 | 起量慢，运营复杂 |

## 8. 基础面试快问快答

问：CTR 低怎么办？

答：先判断是曝光人群不准，还是素材吸引力不够。可以从封面、标题、前 3 秒钩子、价格展示、目标人群匹配度几个方向测试。比如同一个产品可以测试痛点封面、对比封面、价格封面，看哪个点击率更高。

问：CVR 低怎么办？

答：CVR 低说明点击后没有完成购买。我会检查商品页卖点、价格、评价、物流时效、优惠、图片视频是否一致，也会看用户从哪个流量来源进来。如果短视频承诺太夸张，用户进商品页发现不匹配，也会导致转化低。

问：你怎么理解 ROI？

答：ROI 是投入产出比，但在电商中不能只看销售额，还要看利润。比如广告 ROAS 很高，但如果客单价低、运费高、退货率高，最后可能还是亏。所以我会把 ROI 和毛利率、广告费率、退货率一起看。

问：如何做用户画像？

答：我会从国家、人群、场景、痛点、购买顾虑和内容触点来做。比如一个厨房收纳产品，目标用户可能是小户型家庭或租房人群，他们在意省空间、安装简单、价格便宜，所以内容要强调前后对比和安装便利。
