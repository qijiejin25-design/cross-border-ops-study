# 06 选品内容流量转化 SOP

SOP 是标准作业流程。你可以把这份文件当作新人运营每天照着做的流程。

## 1. 选品 SOP

### 第一步：确定市场

先定国家或地区，不要一上来就说“全球都卖”。

要看：

- 消费能力
- 物流时效
- 平台成熟度
- 语言门槛
- 竞争程度
- 季节和节日

### 第二步：确定品类

新手可以优先看：

- 家居收纳
- 美妆工具
- 宠物用品
- 运动健身小件
- 手机配件
- 厨房小工具
- 旅行用品
- 节日礼品

谨慎品类：

- 食品、保健品、药品
- 儿童安全类
- 带电池或液体
- 大件家具
- 强认证要求产品
- 明显涉及品牌/IP 的产品

### 第三步：找商品机会

渠道：

- 平台 Best Sellers/Hot Products
- TikTok Creative Center
- Amazon 搜索和类目榜
- Shopee 热销榜和活动页
- eBay Sold Items
- Google Trends
- Instagram/Pinterest/TikTok 热门内容
- 1688/义乌/供应链网站

### 第四步：打分

| 维度 | 评分 1-5 | 判断标准 |
|---|---:|---|
| 需求 |  | 是否有真实搜索、销量、内容热度 |
| 利润 |  | 扣完成本后是否还能赚钱 |
| 竞争 |  | 新卖家是否有机会进入 |
| 内容性 |  | 是否适合短视频展示 |
| 供应 |  | 供货是否稳定，质量是否可控 |
| 合规 |  | 是否有禁售、认证、侵权风险 |
| 物流 |  | 是否轻小、低破损、低退货 |

总分高于 25 分可以小批量测试。

## 2. 商品页 SOP

### 标题

标题要包含：

- 核心关键词
- 关键属性
- 使用场景
- 人群或规格

不要堆砌无关关键词。

### 主图

主图要清楚展示产品。不同平台有不同规则，尤其 Amazon 主图通常要求白底和无多余元素，必须以平台规则为准。

### 副图

副图承担解释任务：

1. 核心卖点
2. 使用场景
3. 尺寸规格
4. 材质细节
5. 使用前后对比
6. 包装清单
7. 常见问题

### 描述

描述不要只写“高质量、好用”。要写：

- 解决什么问题
- 为什么有效
- 适合谁
- 怎么使用
- 购买前需要知道什么

## 3. 内容 SOP

每个产品至少准备 10 条短视频方向：

1. 痛点解决
2. 使用前后
3. 开箱
4. 测评
5. 教程
6. 场景展示
7. 用户评价
8. 对比竞品
9. 节日送礼
10. 评论区答疑

脚本模板：

| 部分 | 作用 | 示例 |
|---|---|---|
| 开头 1-3 秒 | 抓注意力 | “Stop wasting space under your sink.” |
| 中间 3-12 秒 | 展示解决过程 | 展示安装、使用、对比 |
| 结尾 12-20 秒 | 给行动理由 | “Tap to get it before the sale ends.” |

## 4. 流量 SOP

### 自然流量

- 每天发布稳定数量内容。
- 账号保持垂直。
- 复用表现好的脚本结构。
- 评论区及时回复。
- 用爆款评论做新视频选题。

### 搜索流量

- 收集关键词。
- 标题和描述覆盖核心词。
- 类目属性填写准确。
- 商品页回答用户常见问题。

### 广告流量

小预算测试：

- 测 3-5 个素材。
- 每个素材只改一个变量。
- 先看点击、加购、转化。
- 表现差的及时停。
- 表现好的逐步加预算。

### 达人流量

达人筛选：

- 粉丝人群是否匹配
- 近期视频播放是否稳定
- 评论是否真实
- 是否有带货经验
- 内容风格是否适合产品
- 报价或佣金是否合理

达人合作流程：

达人名单 -> 联系 -> 寄样 -> 提供卖点和禁用话术 -> 跟进发布时间 -> 记录数据 -> 复投优质达人。

## 5. 转化 SOP

转化优化顺序：

1. 商品页首屏是否清楚。
2. 价格是否有竞争力。
3. 优惠是否明显。
4. 评价是否足够。
5. 物流时效是否可接受。
6. FAQ 是否解决顾虑。
7. 视频承诺和商品页是否一致。

## 6. 复盘 SOP

每周复盘回答 6 个问题：

1. 哪些商品带来最多销售额？
2. 哪些商品利润最高？
3. 哪些内容带来最多点击？
4. 哪些流量来源转化最好？
5. 哪些问题导致退款或差评？
6. 下周要停止、继续、加大投入的动作分别是什么？
