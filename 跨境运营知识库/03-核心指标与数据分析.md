# 03 核心指标与数据分析

运营看数据，不是为了做表格，而是为了判断下一步动作。

## 1. 电商漏斗

基础漏斗：

曝光 -> 点击 -> 加购 -> 下单 -> 支付 -> 签收 -> 好评 -> 复购

每一层都有对应指标：

| 阶段 | 指标 | 说明 |
|---|---|---|
| 曝光 | Impressions/Views | 有多少人看到 |
| 点击 | CTR | 看到后有多少人点 |
| 加购 | ATC Rate | 有多少人加入购物车 |
| 下单 | CVR | 有多少点击转成订单 |
| 支付 | Payment Rate | 有多少订单完成支付 |
| 售后 | Return Rate/Refund Rate | 退货退款比例 |
| 评价 | Review Rate/Rating | 评价数量和评分 |
| 复购 | Repeat Purchase Rate | 是否能长期贡献价值 |

## 2. 运营每天应该看什么

### 日报

- 昨日销售额
- 订单数
- 客单价
- 访问量
- 点击率
- 转化率
- 广告花费
- ROAS
- 退款/取消
- 库存预警

日报用于发现异常。例如突然没单、广告花费暴涨、转化突然下降。

### 周报

- 本周 GMV 和利润趋势
- 爆品/滞销品
- 流量来源变化
- 广告素材表现
- 内容发布表现
- 活动效果
- 下周动作

周报用于做决策。例如预算加在哪里，哪些商品下架，哪些内容继续拍。

### 月报

- 品类结构
- 利润结构
- 库存周转
- 广告效率
- 新品成功率
- 用户评价问题
- 团队 SOP 改进

月报用于看业务健康度。

## 3. 常见数据问题和动作

### 曝光高，CTR 低

可能原因：

- 素材不吸引
- 标题太平
- 价格没有竞争力
- 目标人群不准
- 商品本身不是强需求

动作：

- 换封面
- 重写标题
- 前 3 秒加入痛点或结果
- 测试价格/优惠
- 换投放人群或兴趣标签

### CTR 高，CVR 低

可能原因：

- 内容吸引但商品页承接差
- 视频夸大效果
- 价格跳出
- 物流慢
- 评价少
- 运费或税费让用户犹豫

动作：

- 优化详情页首屏
- 增加真实使用图
- 补充尺寸、材质、场景
- 设置优惠券
- 改物流方案
- 用评价和 FAQ 降低顾虑

### CVR 高，流量低

说明商品能转化，但没人看到。

动作：

- 增加内容发布频率
- 做达人合作
- 开广告测试
- 报名平台活动
- 优化关键词
- 做关联销售

### 销售额高，利润低

可能原因：

- 广告费过高
- 价格太低
- 运费过高
- 退货率高
- 平台费和仓储费没算清
- 库存积压造成折价

动作：

- 提价或做套装
- 降低广告预算或优化素材
- 调整物流和仓储
- 下架高退货 SKU
- 优化采购价

## 4. 广告数据基础

广告漏斗：

展示 -> 点击 -> 落地页访问 -> 加购 -> 结账 -> 成交

常见指标：

- CPM：千次展示成本。
- CPC：单次点击成本。
- CPA：单次转化成本。
- ROAS：广告销售额 / 广告花费。
- Frequency：同一个人平均看到广告的次数。

判断广告不能只看 ROAS：

- 新品期：可能先看点击、加购、收藏，积累数据。
- 成熟期：重点看 ROAS、利润、库存和放量稳定性。
- 清库存：可以接受较低利润，但要控制亏损。

## 5. 数据分析方法

### 对比法

和昨天比、上周比、活动前后比、同类商品比。

### 拆解法

销售额下降，不要只说“销量不好”，要拆：

销售额 = 曝光 x 点击率 x 转化率 x 客单价

到底是曝光掉了，点击掉了，转化掉了，还是客单价掉了。

### 分层法

不要把所有商品混在一起看。

- 按国家看
- 按品类看
- 按价格带看
- 按流量来源看
- 按新老用户看
- 按自然流量和广告流量看

### A/B 测试

一次只改一个主要变量，才知道结果来自哪里。

可测试变量：

- 封面
- 标题
- 首图
- 价格
- 优惠券
- 视频开头
- 达人类型
- 广告人群

## 7. 面试表达模板

当面试官问“你如何通过数据优化运营”，可以这样答：

我会先把销售结果拆成曝光、点击率、转化率和客单价。如果曝光低，优先解决流量入口，比如关键词、内容频率、达人和广告；如果 CTR 低，说明素材或商品吸引力不够，会测试封面、标题和前 3 秒钩子；如果 CVR 低，会检查商品页、价格、评价、物流和优惠承接。最后我会用 A/B 测试验证，而不是凭感觉改。
