# 10 术语表

## 基础电商术语

| 术语 | 中文 | 解释 |
|---|---|---|
| GMV | 成交总额 | 一段时间内成交订单金额总和，通常未扣退款和成本 |
| Revenue | 收入 | 实际确认的销售收入，口径要看公司定义 |
| Profit | 利润 | 收入扣除商品、物流、佣金、广告、退货等成本后的结果 |
| SKU | 库存单位 | 一个具体可售卖规格，如黑色 M 码 |
| SPU | 标准产品单位 | 一个产品集合，如一款 T 恤 |
| AOV | 客单价 | 销售额 / 订单数 |
| CAC | 获客成本 | 获取一个新客户的成本 |
| LTV | 生命周期价值 | 一个用户长期贡献的价值 |
| Margin | 利润率 | 利润占销售额的比例 |
| Inventory Turnover | 库存周转 | 库存卖出和补货的效率 |

## 流量和转化术语

| 术语 | 中文 | 解释 |
|---|---|---|
| Impression | 展示 | 内容或商品被看到的次数 |
| Reach | 触达 | 看到内容的独立用户数 |
| Click | 点击 | 用户点击内容、广告或商品 |
| CTR | 点击率 | 点击次数 / 展示次数 |
| CVR | 转化率 | 成交数 / 点击数，具体口径按平台 |
| Add to Cart | 加购 | 用户把商品加入购物车 |
| Bounce Rate | 跳出率 | 用户进入后很快离开的比例 |
| Organic Traffic | 自然流量 | 不直接付费获得的流量 |
| Paid Traffic | 付费流量 | 广告等付费渠道流量 |

## 广告术语

| 术语 | 中文 | 解释 |
|---|---|---|
| CPC | 单次点击成本 | 广告花费 / 点击数 |
| CPM | 千次展示成本 | 每 1000 次展示的成本 |
| CPA | 单次转化成本 | 广告花费 / 转化数 |
| ROAS | 广告支出回报 | 广告销售额 / 广告花费 |
| Creative | 广告素材 | 视频、图片、文案等 |
| Campaign | 广告系列 | 广告账户中的一级结构 |
| Ad Group | 广告组 | 管理人群、预算、出价等 |
| Pixel | 像素 | 用于追踪用户行为和转化的数据工具 |

## Amazon 术语

| 术语 | 中文 | 解释 |
|---|---|---|
| Listing | 商品详情页 | 商品在 Amazon 上的销售页面 |
| FBA | 亚马逊物流 | 亚马逊负责仓储配送和部分客服 |
| FBM | 卖家自发货 | 卖家自己履约 |
| Buy Box | 购买按钮位置 | 影响成交的核心位置 |
| A+ Content | A+ 页面 | 更丰富的图文详情展示 |
| PPC | 点击付费广告 | Amazon 站内广告常见形式 |
| ASIN | 亚马逊商品识别码 | Amazon 商品唯一编号 |

## TikTok 术语

| 术语 | 中文 | 解释 |
|---|---|---|
| For You Page | 推荐页 | TikTok 的主要内容推荐页面 |
| Hook | 钩子 | 视频开头抓住用户注意力的内容 |
| Completion Rate | 完播率 | 看完整条视频的比例 |
| Engagement | 互动 | 点赞、评论、分享、收藏 |
| Affiliate | 联盟/达人带货 | 达人通过佣金推广商品 |
| LIVE | 直播 | 实时直播带货或互动 |
| Product Card | 商品卡 | 视频或直播中的商品入口 |
| Spark Ads | Spark 广告 | 放大自然内容或达人内容的广告形式 |

## eBay 术语

| 术语 | 中文 | 解释 |
|---|---|---|
| Fixed Price | 固定价 | 以固定价格出售 |
| Auction | 拍卖 | 买家竞价购买 |

## 合规和履约术语

| 术语 | 中文 | 解释 |
|---|---|---|
| IP Infringement | 知识产权侵权 | 使用他人品牌、图片、专利、版权等 |
| VAT/GST | 增值税/消费税 | 不同国家地区的税务要求 |
| Fulfillment | 履约 | 从订单到送达的过程 |
| 3PL | 第三方物流 | 外部物流服务商 |
| Overseas Warehouse | 海外仓 | 在目标市场本地仓储发货 |
| Return Rate | 退货率 | 退货订单比例 |
| Chargeback | 拒付 | 买家通过支付渠道发起的款项争议 |
