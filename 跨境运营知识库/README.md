## 你要建立的完整知识链

跨境运营不是“发发视频、上上产品”。完整链路是：

市场需求 -> 用户画像 -> 选品 -> 定价 -> 素材和内容 -> 流量获取 -> 商品页转化 -> 订单履约 -> 售后评价 -> 数据复盘 -> 放大盈利模型。

面试时，面试官最想知道三件事：

1. 你懂不懂业务链路：钱从哪里来，成本在哪里，增长靠什么。
2. 你懂不懂平台逻辑：不同平台的流量、成交、履约和规则差异。
3. 你能不能落地执行：能不能做选品、写内容脚本、看数据、改动作。

## 使用方法

第一遍学习不要追求背诵。先理解“为什么这样做”，再记术语。

每天建议固定输出三样东西：

1. 一页笔记：今天学了哪些概念。
2. 一个小练习：比如拆一个 TikTok 视频、分析一个商品页。
3. 一个面试答案：用 STAR 或“定义-方法-案例-结果”结构回答。
